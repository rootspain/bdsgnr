# Связи по типу детонатора, список «Продукт» у связи, ЭСИ и магистральная линия — план

Согласовано 2026-11-22, версия 0.3.11. Сделано 2026-11-22: правило — `Engine/TieFit.cs` (`Refusal`, `Offered`),
каталог на ЭСИ — `MainViewModel.PreferEsiTies`, переименования — `ProductCatalogue.RenameBusLineAndEsi`,
`HiddenKindNames`. Отличие от плана: правило формы цепочки ЭСИ (`RouteNumbers.Refusal`) по-прежнему действует для
скважин с электронным детонатором при любой связи, в том числе для смешанных скважин.

## 1. Связь подходит скважинам по типу детонатора

Сейчас инструмент «Связь» проверяет у скважин с электронным детонатором только форму цепочки
(`RouteNumbers.Refusal`: без ветвлений, без колец, вход в начало цепочки). Изделие связи не проверяется: между
электронными скважинами можно провести НСИ, ДШ или «0 мс».

Правило (одно, в движке рядом с `RouteNumbers.Refusal`):

- **Связь ЭСИ** — изделие вида «Электронный детонатор». Каждая скважина на концах связи имеет хотя бы один электронный
  боевик.
- **Связь не-ЭСИ** — НСИ, ДШ, реле ДШ, электрическая, магистральная линия, «0 мс», своя задержка. Каждая скважина на
  концах имеет хотя бы один неэлектронный боевик.
- Смешанная скважина (оба вида боевиков) подходит к обоим типам связей.
- Конец на точке инициирования не ограничивает; скважина на другом конце проверяется как выше.
- Скважина без боевиков (ещё не заряжена) принимает любую связь.
- Нарушение — **отказ**: связь не создаётся, в строке состояния номер скважины и подсказка, какое изделие выбрать
  в «Каталоге СИ». Изделие не подменяется.

Где работает: инструмент «Связь» (и цепочка через скважины по пути), «Связать выделенные по порядку»,
«Автоматическая обвязка», смена изделия в свойствах связи (п. 3).

## 2. «Каталог СИ» открывается на ЭСИ

Если в блоке есть скважины с электронными детонаторами и в проекте ещё нет выбора каталога (`TieSystem`), при открытии
проекта и при первом нажатии «Связь» активен тип ЭСИ и первое изделие ЭСИ. Дальше каталог помнит выбор пользователя,
сам по щелчкам не переключается.

## 3. Список «Продукт» в свойствах связи

Сейчас его даёт `MainViewModel.AddProductChoices` по жёсткому `Product.IsTieProduct` (соединители, ДШ, реле ДШ,
провод): нет электронных (Davey Tronic) и электрических детонаторов, порядок — как в «Ресурсах», с «Каталогом СИ» не
связан.

Станет:

1. **Источник — типы «Каталога СИ»:** изделия видов, входящих в типы каталога (без удалённых). Тип «Своя задержка»
   не даёт изделий — для неё поле «Замедление, мс». `IsTieProduct` уходит из выборки.
2. **Фильтр по концам связи** — правило п. 1; для нескольких выделенных связей — подходящие всем.
3. **Порядок и подписи:** по порядку типов каталога, внутри — по семейству и замедлению; строка с кратким именем типа:
   «НСИ · Surface connector 17 ms», «ЭСИ · Davey Tronic», «BusLine · Bus line».
4. Текущее изделие связи остаётся в списке, даже не подходя, с пометкой «(не подходит)».

## 4. Переименования

| Что | ru | en |
|---|---|---|
| Тип ЭСИ, краткое имя (чип каталога, подписи списка) | ЭСИ | ESI |
| Тип ЭСИ, полное имя (подсказка, Ресурсы ▸ Типы) | Электронные системы инициирования | Electronic Initiation System |
| Тип Harness wire, краткое имя | BusLine | BusLine |
| Тип Harness wire, полное имя | Магистральная линия | Bus line |
| Вид продукта Harness wire (чип «Ресурсов», «Вид», заголовок группы) | Магистральная линия | Bus line |
| Встроенное изделие Harness wire | Bus line | Bus line |

- Id типов, видов и изделий не меняются; краткое имя, заданное пользователем в проекте, не трогается.
- Изделие «Harness wire» во встроенном справочнике — «Bus line». В проекте и в справочнике пользователя изделие того же
  id с именем «Harness wire» переименовывается при открытии; своё имя пользователя остаётся.
- «EBS» → «ESI» во всём английском интерфейсе: «ESI field report», «ESI opening point» / «Edit ESI opening point»,
  сообщения экспорта Davey Tronic про связи. Русские тексты там уже «ЭСИ». Ключи ru.tsv переименовываются вместе с
  текстом. `KindName` точки открытия («EBS opening point») хранится в настройках видимости: старое имя читается и
  переводится в новое. «Davey Tronic (.BPD)» — имя формата, не меняется.
