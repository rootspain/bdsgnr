# Полигон → сетка скважин — план

Статус: согласован и сделан 2026-11-13.

## Что нужно

Выделенный замкнутый полигон превращается в сетку скважин: пользователь задаёт параметры сетки, видит результат на
плане до применения, нажимает «Применить» — скважины, ряды и сетка созданы одним шагом отмены.

## Что уже есть

- **Инструмент «Сетка» (P)** — пользователь щёлкает точки контура, и сетка заполняет его сразу. Параметры берутся с
  панели инструмента и из «Проектных данных» (`MainViewModel.PatternTool` → `FillPolygon`).
- **«Скважины ▸ Заполнить выделенный полигон…»** и кнопка «Fill polygon» в панели инструментов. Спрашивает параметры
  стандартным окном свойств объекта (`Dialogs.EditObject` над `PatternParameters`), без предпросмотра.
- **Движок** `HoleDesign.FillPolygon` / `CreatePattern`
  ([HoleDesign.Patterns.cs](../src/BlastDesigner.Engine/HoleDesign.Patterns.cs)):
  - сетка прямоугольная или шахматная;
  - ряды идут поперёк направления взрыва (`Orientation`);
  - отступ от края (`EdgeOffset`), префикс и первый номер;
  - сетка (`HolePattern`) сохраняется в проекте со ссылкой на полигон (`OutlineEntityId`). Её можно повернуть
    мышью, перестроить, отвязать скважины, распустить.
  - Начало сетки — угол охватывающего прямоугольника полигона плюс половина шага. Первый ряд не привязан ни к одной
    стороне полигона.
- **Слежение** (`FollowPatterns`): сетка следует за своими скважинами (удалённая скважина оставляет пустой узел,
  сдвинутые вместе — сдвигают сетку). Правка самого полигона сетку не перестраивает: только вручную «Перестроить сетку».

Чего не хватает: предпросмотра, привязки первого ряда к стороне полигона (к откосу), понятного окна, работы с
несколькими полигонами сразу и, возможно, живой связи полигон → сетка.

## Предлагаемое устройство

### 1. Запуск

- **Контекстное меню** выделенного замкнутого полигона: «Превратить в сетку скважин…».
- **Лента**, «Расстановка ▸ Сетка»: кнопка с тем же действием, когда выделен полигон. Без выделения кнопка запускает
  инструмент «Сетка» как сейчас.
- Действующая «Заполнить выделенный полигон…» открывает то же новое окно, вместо окна свойств объекта.

### 2. Окно «Сетка из полигона» (немодальное, план остаётся доступен)

Поля:

- **Тип:** прямоугольная / шахматная.
- **ЛНС (B) и расстояние между скважинами (S),** м.
- **Направление рядов:**
  - (а) вдоль стороны полигона — выбор щелчком по стороне на плане, сторона подсвечивается; первый ряд идёт
    параллельно ей;
  - (б) по азимуту взрыва — число, по умолчанию направление взрыва из свойств блока;
  - кнопки «повернуть на 90°» и «развернуть на 180°» (с какой стороны начинается первый ряд).
- **Первый ряд от стороны,** м: по умолчанию B/2 (см. вопрос 2).
- **Отступ скважин от контура,** м: скважина ближе к краю не ставится.
- **Выравнивание по длине ряда:** от начала стороны / по центру / подогнать S, чтобы крайние скважины встали на
  отступ от краёв (см. вопрос 3).
- **Скважины:** диаметр, угол, азимут наклона, перебур, высота уступа, тип скважины — по умолчанию из «Проектных
  данных».
- **Отметка:** длина по уступу / до отметки / до поверхности — как на панели инструмента «Сетка».
- **Нумерация:** префикс, первый номер, порядок (по рядам от первого / змейкой).
- **Полигон после:** оставить как границу сетки (рекомендую) / удалить (см. вопрос 4).
- Внизу: «Скважин: N, рядов: M, площадь на скважину B×S», кнопки «Применить» и «Отмена».

### 3. Предпросмотр

- Пока окно открыто, на плане квадратами показываются будущие скважины (`PreviewOverlay.Markers`, как у поворота
  сетки), тонкими линиями — ряды, стрелкой — направление взрыва, выбранная сторона подсвечена.
- Любое поле окна сразу перестраивает предпросмотр. Расчёт — тот же `HoleDesign.FillPolygon` без записи в проект, так
  что предпросмотр совпадает с результатом.
- Стрелку направления можно повернуть мышью кругом на конце, как у готовой сетки (`PatternRotateHandle`).

### 4. Несколько полигонов

Если выделено несколько замкнутых полигонов, окно одно, а сеток получается несколько — по одной на полигон, с
одинаковыми параметрами. Нумерация идёт сквозная. Направление «вдоль стороны» при нескольких полигонах берётся у
каждого своё: самая длинная сторона (см. вопрос 5).

### 5. Движок

Расширение `PatternParameters` и `CreatePattern`:

- `FirstRowEdge` (индекс стороны) и `FirstRowOffset`: азимут — перпендикуляр к стороне внутрь полигона, фаза по V —
  так, чтобы первый ряд шёл на заданном расстоянии от стороны;
- `Alignment` по U (от начала, по центру, подогнать S);
- без новых полей поведение прежнее: старые проекты и инструмент «Сетка» не меняются.

Сетка, как и сейчас, сохраняется в проекте (`HolePattern` с `OutlineEntityId`), так что потом её можно повернуть,
перестроить и распустить теми же командами.

### 6. Связь полигон → сетка (см. вопрос 1)

Вариант «живая связь»: правка вершин полигона перестраивает его сетку сама, через `Document.Followers`, как
поверхность следует за исходными объектами. Скважины, которые уже пробурены, заряжены или заблокированы, сетку не
дают перестроить (`RebuildRefusal`): тогда правка полигона проходит, а сетка остаётся, в строке состояния — почему.

### 7. Обязательная часть

- Тексты окна, меню, подсказок — в ru.tsv.
- CHANGELOG.md и CHANGELOG.en.md.
- Unit-тесты движка: первый ряд параллелен стороне и на заданном расстоянии; разворот на 180°; выравнивание по
  центру и подгонка S; шахматная сетка; несколько полигонов — сквозная нумерация; живая связь (если будет) —
  перестройка после правки вершины и отказ при пробуренной скважине.
- Шаг UiSmoke: выделить полигон, открыть окно, выбрать сторону, поменять B — предпросмотр меняется, «Применить» —
  скважины созданы, одна отмена убирает всё.

## Решения (2026-11-13)

1. Правка полигона сама перестраивает сетку (`PatternOutlines.Follow`, тем же шагом отмены). Сетка, повёрнутая вручную,
   перестаёт следовать за стороной: при правке полигона меняется только контур. Пробуренные, заряженные,
   заблокированные скважины — сетка остаётся, в строке состояния причина.
2. Первый ряд на B/2 от стороны.
3. Выравнивание вдоль ряда — три варианта на панели: по левому краю, по центру, по правому краю (если смотреть по
   направлению взрыва).
4. Полигон остаётся границей сетки.
5. Несколько полигонов сразу, у каждого первый ряд вдоль самой длинной стороны; щелчок по стороне любого из них
   выбирает её. Нумерация сквозная.
6. Контурный ряд — не делаем.

Окно создания — панель инструмента «Сетка из полигона» внизу плана, как у инструмента «Сетка»: те же поля плюс
«Вдоль ряда»; направление задаётся стороной, поля азимута нет.
