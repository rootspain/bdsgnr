# Распознавание элементов уступа: как пользоваться

Программа находит в маркшейдерской съёмке верхние и нижние бровки, горизонтали и контуры блоков, показывает уступы с высотой и углом откоса и по вашему подтверждению назначает линиям типы и строит поверхность по съёмке.

Распознавание делает обученная модель (экспериментально) или набор правил. Результат — подсказка: перед применением его нужно проверить.

## Что нужно

Съёмка забоя в DWG или DXF:

- **пикеты с отметками** — точки (`POINT`) с высотой или блоки с атрибутом отметки;
- **линии съёмки с высотами** — 3D-полилинии (бровки, подошвы, горизонтали).

Линии на высоте 0 (сетка, проектный контур, подписи) в распознавании не участвуют. Скважины в проекте помогают распознаванию, но не обязательны.

## 1. Импорт съёмки

1. **Файл ▸ Импорт ▸ DXF / DWG…** (или перетащите файл в окно программы).
2. В окне **«Параметры импорта DXF»**:
   - **Скрытые слои** — что делать со слоями, выключенными или замороженными в чертеже:
     - *Импортировать скрытыми* (по умолчанию) — всё придёт в проект, но такие слои будут выключены;
     - *Пропустить* — останется только то, что видно в чертеже; обычно это и есть съёмка;
     - *Импортировать видимыми*.
   - **Отделять плоские линии** (включено) — линии на высоте 0 уйдут в отдельные слои «имя (2D)» и не смешаются со съёмкой.
3. В строке состояния будет видно, сколько объектов импортировано и сколько плоских линий отделено.

## 2. Запуск распознавания

Вкладка ленты **«Топография» ▸ группа «Поверхности» ▸ «Распознать (AI)»** (или меню **Инструменты ▸ Поверхности ▸ Распознать элементы уступа…**).

- Если что-то **выделено**, распознаются только выделенные линии и точки.
- Если ничего не выделено — вся съёмка на **видимых** слоях. Чтобы исключить лишнее, выключите его слои или выделите нужную часть.

Откроется окно **«Элементы уступа»**, а на плане линии раскрасятся по классам. Эта раскраска — только пока окно открыто; после применения цвета и видимость задают слои (см. раздел 4).

## 3. Окно «Элементы уступа»

### Способ: модель или правила

Вверху два переключателя:

- **Модель (эксперимент.)** — обученная модель. На синтетических съёмках она заметно точнее правил, особенно отличает бровки от дорог и валов; на реальных съёмках пока не проверена.
- **Правила** — простые геометрические правила: перепад высот рядом с линией, пикеты по сторонам.

Переключение распознаёт съёмку заново, сделанные правки при этом пропадают. Выбор запоминается для следующего раза. Если кнопка модели неактивна, модель не загрузилась; причина — во всплывающей подсказке.

### Что показано

**Линии** — длина по классам:

| Цвет на плане | Класс |
|---|---|
| красный | верхняя бровка |
| синий | нижняя бровка |
| зелёный | горизонталь |
| фиолетовый | граница (контур блока) |
| серый | прочее (дороги, валы, всё остальное) |

**Пунктир** — распознавание не уверено. Число таких участков показано рядом с длиной («проверить: N»). Начинайте проверку с них.

**Уступы** — для каждой верхней бровки: отметка, высота уступа, ширина и угол откоса (если найдена нижняя бровка), длина. Нелепые значения (откос 1 м под 86°, высота 2 м) — признак ошибки распознавания рядом с этой бровкой.

### Как исправить

Линии разбиты на участки примерно по 15 м, у каждого свой класс.

- **Щелчок** по участку на плане — следующий класс по кругу.
- **Ctrl+щелчок** — то же для всей линии.
- **Правая кнопка** по участку — меню с выбором класса для участка или всей линии.

Таблица уступов пересчитывается сразу. Пока окно открыто, в проекте ничего не меняется.

## 4. Применение

Внизу окна:

- **Назначить линиям тип** — бровки получат тип «Бровка» / «Подошва (низ откоса)», горизонтали — «Изолиния», границы — «Контур». Эти типы используют другие функции программы, например «Профиль первого ряда».
- **Разрезать линии там, где меняется класс** — если часть линии бровка, а часть дорога, линия будет разрезана на куски с разными типами. Без этого линия получит тип того класса, которого в ней больше по длине.
- **Разложить линии по слоям типов, в их цветах** (включено) — линии переходят в слои группы «Топография»:

  | Слой | Цвет | Тип линии |
  |---|---|---|
  | Верхние бровки | красный | Бровка |
  | Нижние бровки | синий | Подошва (низ откоса) |
  | Горизонтали | зелёный | Изолиния |
  | Контуры блоков | фиолетовый | Контур |

  Собственный цвет линии из чертежа сбрасывается, и линия рисуется цветом слоя. Каждый тип включается и выключается своим слоем в панели слоёв, там же меняется его цвет. Линии класса «прочее» остаются в своих слоях. Галочка доступна, только если включено «Назначить линиям тип». Тип, поменянный вручную на вкладке «Свойства», переносит линию так же; линия без типа уходит из этих слоёв в слой «Съёмка».
- **Построить поверхность по съёмке** — поверхность по пикетам, где **все** линии съёмки с высотами (бровки, дороги, валы, горизонтали, контуры) служат структурными линиями: треугольники не пересекают ни одну из них, поверхность проходит точно по линиям. Класс линии на построение не влияет. В слое «Поверхности» появятся две поверхности:
  - **«Откосы»** с типом «Откос» — треугольники между распознанными верхними и нижними бровками, а также крутые (больше 30°) треугольники, касающиеся бровки;
  - **«Поверхность съёмки»** — всё остальное: бермы, площадки, дороги, валы.

  Цвет откосов задаётся в «Настройки программы ▸ Вьюпорт ▸ Цвета поверхностей ▸ Откос» (при окраске поверхностей по типу). Скрытые слои в построение не попадают: выключите слои с проектными контурами и контурами отработанных блоков — линии разных горизонтов, пересекающиеся в плане, нельзя соблюсти одновременно.

**Применить** — всё одним шагом; отменяется одним **Отменить** (Ctrl+Z). **Отмена** — закрыть окно без изменений.

## 5. Помочь улучшить распознавание

Модель обучена только на синтетических съёмках. Самое полезное, что можно сделать, — проверенная вручную разметка реальных съёмок:

1. Распознайте съёмку и исправьте все ошибки щелчками.
2. Нажмите **«Сохранить разметку…»** и сохраните файл JSON.

В файле только классы участков; линии в нём названы условным кодом, координат и имён нет. Передайте файл вместе с названием съёмки разработчикам — по нему измеряется точность и дообучается модель.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Нет линий съёмки с высотами» | Съёмка не импортирована, линии плоские (высота 0) или их слои выключены. Проверьте импорт и видимость слоёв. |
| «Уступов не найдено» | Рядом с линиями нет перепада на высоту уступа: нет пикетов на площадках или нижних уровней. Проверьте, что пикеты импортированы с отметками. |
| Много лишних линий в результате | Выключите слои с чертежом (сетка, проект, подписи) или выделите только съёмку перед запуском. |
| Модель и правила дают разное | Сравните оба способа переключателем; где они расходятся — смотрите внимательнее. Модель экспериментальная. |
| Кнопка «Модель» неактивна | Модель не загрузилась (подсказка на кнопке объясняет почему). Распознавание по правилам работает. |
