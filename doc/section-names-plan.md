# Названия линий разреза — план

Сделано 2026-11-20 (0.3.10). Код: `Engine/SectionNames.cs` (ряд, `Follow` в `Document.Followers`, `NameAll` при
открытии в `ProjectFile`), карточка — `PropertiesPanel.SectionNameCard` (`Views/Panels.cs`), буквы на плане —
`PlanRenderer.DrawSectionName`. Дизайн панели: https://claude.ai/artifact/LFGPESxfUyszwMH1iuSoqv. Группы «Геометрия» /
«Оформление» из дизайна и строка «Азимут» не сделаны: поля идут общей таблицей свойств, как у прочих линий.

Каждая линия разреза получает название по порядку, латинской буквой: A, B, C… По чертёжной традиции буква стоит у
каждого конца линии, а разрез называется «A–A». Название правится в панели свойств, повтор запрещён.

## Что есть сейчас

- Линия разреза — это `PolylineEntity` с `Kind = LineKind.CrossSection`. Создаётся в `MainViewModel.Tools.cs`
  (шаг отмены «Add section line»).
- У линии уже есть поле `Label`. Сейчас оно пустое и видно в общей таблице свойств как обычная метка.
- Листы разрезов (`Reports.SectionEnds`) подписываются этим `Label`, а без него — номером по порядку (1, 2…).
- На плане название линии не рисуется. В окне «Разрез» показан только номер «1 / 3».

## Что делаем

1. **Название по порядку** — `Engine/SectionNames.cs`:
   - `Name(i)` даёт A, B … Z, после них A1, B1 … Z1, затем A2 и так далее;
   - `Next(project)` даёт первое название ряда, которого нет у других линий разреза. Удалили B — новая линия снова
     получит B;
   - `Caption(name)` даёт «A–A», так название пишется в окне «Разрез» и на листе.
   - Хранится сама буква в `Label` («A»).
2. **При создании.** Инструмент «Линия разреза» записывает `Label = SectionNames.Next(project)` в том же шаге отмены.
3. **Вставка и копирование.** Вставленная линия разреза, чьё название уже занято, получает `Next`. Вставка из
   другого проекта тоже.
4. **Старые проекты.** При открытии линии разреза без названия получают названия в своём порядке. Это не шаг отмены,
   и проект от этого не помечается изменённым. Свои метки линий не трогаются.
5. **Панель свойств.** Для одной выделенной линии разреза — поле «Название разреза» под «Слоем» (как «Литера
   маршрута»). Общая строка «Метка» для такой линии скрыта.
   - Ввод применяется по Enter или потере фокуса одним шагом отмены «Изменить Название разреза».
   - Пробелы по краям убираются, длина до 12 знаков. Можно ввести и не букву («1», «Север»).
   - Пустое поле возвращает название по порядку.
   - Повтор запрещён: название, которое уже есть у другой линии разреза, не принимается. Поле подсвечивается,
     внизу подсказка «Название A уже у другой линии разреза», значение остаётся прежним.
6. **План.** Буква рисуется у обоих концов линии, снаружи за концом, цветом линии разреза, крупнее подписей скважин.
   Её скрывает переключатель «Текст» на вкладке «Видимость» и слоя, как прочие подписи.
7. **Окно «Разрез».** Рядом с номером — название: «A–A · 1 / 3».
8. **Лист печати.** «Разрез A–A» (`Reports.SectionEnds` берёт `SectionNames.Caption(Label)`). Номер вместо названия
   остаётся только для линии без названия.

## Тексты

Новые ключи в `ru.tsv`: «Section name» → «Название разреза» и «Section name {0} is taken by another section line» →
«Название {0} уже у другой линии разреза». Шаг отмены — через существующий «Edit {0}».

## Тесты

- Юнит-тесты `SectionNamesTests`:
  - ряд названий: A, B … Z, A1;
  - подпись «A–A»;
  - `Next` занимает пробел после удалённой линии;
  - вставка с занятым названием получает новое;
  - в старом проекте названия раздаются в порядке линий, а своя метка остаётся;
  - лист разреза называется «… A–A».
- UiSmoke:
  - две линии разреза получают A и B;
  - поле «Название разреза» в свойствах: переименование в «Север» и отмена, повтор B отклоняется, пустое поле
    возвращает A;
  - окно «Разрез» показывает «A–A»;
  - снимок плана с буквами у концов.
