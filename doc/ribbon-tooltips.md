# Подсказки кнопок ленты

Статус: сделано (0.3.11).

## Формат

```
Выровнять шаг                                 Ctrl+…
Выравнивает шаг в рядах: крайние скважины на месте,
промежуточные — на равные шаги между ними.
Ряды выделенных скважин, а если ничего не выделено — все ряды.
Недоступно в Blast Designer
```

1. **Заголовок** — название жирным; клавиша, если есть, справа, приглушённо.
2. **Что делает** — 1–2 предложения, с глагола, без повтора названия.
3. **На что действует** — приглушённо, только если не очевидно. Общие фразы:
   - `Ask` — «Если выделены скважины, спросит: только их или все.» (команды через `AskHoles`);
   - `SelectedOrAll` — «Выделенные скважины, а если их нет — все.» (`SelectedOrAllHoles`);
   - `Selected` — «Действует на выделенные скважины.»;
   - `Tool` — «Инструмент: работает щелчками по чертежу; Esc — выход.».
4. **Почему недоступна** — приглушённо, курсивом; сейчас это `Lock` у кнопок, которых нет в программе.

Ширина не больше 360 пикс., текст переносится. Размер, фон и цвет — из Настройки ▸ Оформление ▸ «Подсказка»
(подсказка передаёт их вниз; приглушённые строки — прозрачностью 0,65, а не своим цветом).

## Где

- `src/BlastDesigner.App/Services/RibbonHints.cs` — описания: ключ — название кнопки (`Label`), текст — обычный ключ
  ru.tsv (`Loc.T`).
- `Ui.TipView(RibbonItem)` в `Views/Shell.cs` — вид подсказки; `Ui.Tip` — то же одной строкой текста (для
  `AutomationProperties.HelpText`).

## Проверки (UiSmoke)

- «ribbon commands resolve»: у каждой кнопки ленты (кроме `Lock`) есть описание; нет описаний кнопок, которых нет;
  подсказка «Выровнять шаг» — три строки (жирное название, описание, приглушённая область); клавиша справа.
- «shell translations»: все описания переведены.

Новая кнопка ленты без описания роняет смоук — описание нужно добавить в `RibbonHints` и ru.tsv.
