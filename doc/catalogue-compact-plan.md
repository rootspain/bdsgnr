# Компактное окно «Каталог СИ» (вариант A) — план

Сделано 2026-11-20 (0.3.10): всё по плану ниже. Короткие имена встроенных типов — `ProductCatalogue.BuiltInShortNames`,
перевод — `Loc.Short` (ключи `short:…` в `ru.tsv`), плотный чип — `Ui.CompactChip`. Smoke: шаги «resources: the tables…»
(поле `tableShortName`) и «initiation catalogue…» (снимки 39d, 39e вместо отдельного 53).

Дизайн: https://claude.ai/artifact/9RKu4cBGcM6b3F64SrCDUW, артборд «A · Плотный список — 260 px».
Окно — `TiePaletteWindow` в `src/BlastDesigner.App/Views/DialogWindows.cs`.

## Что меняется

1. **Окно.** Ширина 380 → 260, высота 640 → 560. Поля 10 px вместо 16, промежутки между разделами 10 px вместо 14.
   Сохранённое место окна (`ProgramSettings.Window["TiePalette"]`) остаётся.
2. **Текущий выбор (верхняя карточка).** Цветная метка 6×30 вместо 10×38. Название одной строкой, 13 px. Путь «тип ›
   вид» 10,5 px, тип в нём — короткое имя (п. 5). Обе строки обрезаются «…», полный текст — в подсказке. Кнопка
   «Соединение 0 мс» становится «0 мс», полная надпись — в подсказке.
3. **Заголовки разделов.** «ТИП», «СЕМЕЙСТВО», «ВАРИАНТ» без кружков с номерами (`Step` → `Caption`), 10 px.
4. **Плотные чипы.** Новый `Ui.CompactChip`: высота 22, скругление 6, отступы 8, шрифт 11. Старый `Ui.Chip` не меняется:
   им пользуются другие окна.
5. **Типы — короткими именами.**
   - Новое поле `CatalogueType.ShortName`.
   - Встроенные типы получают его в `ProductCatalogue.BuiltIn()` (ключи перевода, `ru.tsv`):

     | Тип | en | ru |
     |---|---|---|
     | Shock tube | Shock tube | НСИ |
     | Cord delay | Cord delay | Замедл. шнура |
     | Detonating cord system | Det. cord | ДШ |
     | Electric | Electric | Электрич. |
     | Harness wire | Harness | Harness |
     | EBS detonators | EBS | EBS |
     | User defined | Own delay | Свой |

   - Тип из старого проекта или файла без короткого имени: по `Id` встроенного типа берётся его короткое имя; у
     своего типа без короткого имени показывается полное.
   - Поле «Краткое имя» в «Каталоге» (`CatalogueEditor`, таблица «Типы») рядом с «Название».
   - Полное имя типа — подсказка чипа.
6. **Семейства — плотный список.** Одна рамка вокруг всех строк, строка 28 px (отступы 6/8). У выбранной строки
   фон и полоса слева цвета акцента. Справа просто число вариантов вместо «вариантов: N». Вид и производитель (сейчас
   вторая строка) уходят в подсказку строки.
7. **Варианты.** Плотные чипы, цветной квадрат 8 px. Замедления — моноширинным шрифтом.
8. **Свой тип (задержка).** Поле высотой 26 и шириной 90 вместо 32 × 120.
9. **Пустые состояния** («Нет изделий этого типа…») — шрифт 11, тот же отступ.

Поведение не меняется: те же выбор, переключение инструмента «Связь» и запоминание семейства по типу. Имена
элементов для smoke остаются: `tieCurrentCard`, `tieCurrent`, `tieTypes`, `tieFamilies`, `tieVariants`, `tieUserDelay`,
теги `type:`, `family:`, `variant:`, `none`.

## Тексты

Новые ключи в `ru.tsv`: короткие имена типов (п. 5), «0 ms», «Short name», подсказки «Connection 0 ms» и «Full name: {0}» при необходимости. Перед добавлением проверить, нет ли уже такого ключа (в `ru.tsv` есть повторы, например «Detonating cord»).

## Тесты

- Юнит-тесты:
  - у встроенных типов есть короткое имя;
  - тип без короткого имени: встроенный получает его по `Id`, свой показывает полное;
  - `ShortName` переживает сохранение и чтение проекта и пользовательского каталога.
- UiSmoke, шаг каталога:
  - ширина окна ≤ 260;
  - у чипа EBS текст короткий, подсказка — полное имя;
  - строка семейства не выше 30 px, выбор семейства и варианта работают как раньше;
  - кнопка «0 мс» сбрасывает выбор;
  - короткое имя меняется в «Каталоге» и попадает в окно;
  - снимок `53_tie_catalogue_compact.png`.

## Решено по ходу

- Короткие имена — поле каталога, а не таблица в коде: свои типы тоже можно сократить.
- Высота окна не подстраивается под содержимое: окно можно растянуть, длинный список прокручивается.
