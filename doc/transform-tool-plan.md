# План: инструмент «Трансформация»

**Сделано 2026-11-15, все этапы.** Отличия от плана — в разделе 7.

Инструмент меняет положение выделенных объектов в пространстве:

- **наклон** по осям X, Y и Z (поворот вокруг каждой оси);
- **масштаб** по каждой оси отдельно или по всем осям сразу;
- **зеркало** по X и по Y — отдельными кнопками.

Есть два режима работы:

- **рамка** — тянуть ручки на плане;
- **числа** — ввести значения в панели.

Пока значения меняются, на плане виден предварительный результат. «Применить» записывает его одним шагом отмены.

## 1. Что уже есть

| Что | Где | Ограничение |
|---|---|---|
| Окно «Преобразование координат»: сдвиг, поворот в плане, один общий масштаб | `MainViewModel.TransformCoordinates`, `TransformParameters`, кнопка «Трансформация» в группе «Линии и полигоны» | только плоскость XY; масштаб один на все оси; результат виден только после «ОК» |
| `GeneralOps.MakeTransform(сдвиг, поворот, центр, масштаб)` | Engine | функция точки, только в плане |
| `Entity.Transform(Func<Vec3, Vec3>)` у всех объектов | Domain | у каждого типа свои правила (см. раздел 3) |
| `RotateSelection` и поворот сетки узора | `MainViewModel.Patterns` | пропускает заблокированные скважины и слои, перепрограммирует линии времени |
| Предварительный показ сдвига | `SceneOptions.MovedEntities` / `MoveOffset` | только сдвиг, без поворота и масштаба |

## 2. Математика

Новый тип `Affine3` в `Domain/Geometry`: матрица 3×3 плюс сдвиг. Умеет `Apply(Vec3)`, `Then(Affine3)`, `Inverse()` и `IsUniformScale`. Трансформация собирается так:

```
p' = центр + Rz(наклон Z) · Ry(наклон Y) · Rx(наклон X) · S(sx, sy, sz) · (p − центр)
```

- **Порядок действий.** Сначала масштаб, затем наклон X, Y и Z. В этом порядке масштаб «по X» означает вдоль оси X самого объекта до наклона, и числа в панели не зависят друг от друга.
- **Оси.** По умолчанию оси мировые: X — восток, Y — север, Z — вверх. Можно выбрать **оси объекта**: для блока — его азимут, для узора — азимут сетки, для выделения из одной линии — направление её первого отрезка. Тогда масштаб «по длине» блока или узора задаётся одним полем.
- **Базовая точка**, вокруг которой идут масштаб, наклон и зеркало, выбирается из списка:
  - центр рамки выделения (по умолчанию);
  - центр низа рамки (наклон «от подошвы»);
  - любой из 8 углов рамки на плане;
  - точка, указанная щелчком (с привязками);
  - точка, заданная координатами.
- `GeneralOps.MakeTransform` остаётся и строится через `Affine3`. Старое окно даёт тот же результат, это проверит тест.

## 3. Как трансформируется каждый тип объекта

Одна функция точки годится не для всех: часть объектов хранит размеры, углы и сетки, а не только точки. Для таких объектов в `Entity` появляется второй метод, `Transform(Affine3 t, TransformRules rules)`. По умолчанию он вызывает старый `Transform(t.Apply)`, а сложные типы переопределяют его.

| Объект | Поведение | Чего не допускается |
|---|---|---|
| Полилиния, поверхность, размер, стрелка, точка, линия времени | каждая вершина через `t`; у поверхности сбрасывается индекс | — |
| Линия времени, шеврон | точки через `t`, затем `ReprogramTimingLines`, как сейчас. Шеврон после неравномерного масштаба может перестать быть прямым — тип берётся по форме (`TypeByShape`) | — |
| **Скважина** (одиночная) | **не трансформируется**: ни масштаб, ни наклон (в том числе вокруг Z), ни зеркало. Для неё есть свойства скважины | пропускается. В строке состояния: «Скважины не трансформируются: N» |
| **Узор** и его скважины | **не меняются совсем**: для узора есть свой инструмент — сетка и её поворот | пропускаются. В строке состояния: «Узоры не меняются: N скважин» |
| **Блок** | начало через `t`, азимут — по наклону Z, длина, ширина и высота — по масштабу вдоль осей блока. Масштаб по мировым осям, не совпадающим с осями блока, считается вдоль его осей, об этом подсказка | наклон по X и Y: стенки блока вертикальны. Блок при таком наклоне пропускается **без сообщения**; наклон Z (поворот в плане) он принимает |
| **Окружность** | масштабируется **только равномерно**: центр через `t`, радиус × масштаб. Когда в выделении есть окружность, замок «Пропорционально» включён и не выключается: изменение одной оси пересчитывает остальные. У боковых ручек рамки тоже пропорциональный масштаб. Подсказка у замка: «В выделении окружность: масштаб только пропорциональный». Наклон переносит только центр | эллипса не бывает |
| Текст | позиция через `t`, высота × масштаб (среднее по X и Y), поворот текста + наклон Z | наклон X и Y меняет только позицию |
| Точка инициирования, точка открытия ЭСИ | позиция через `t`, у точки открытия — направление, как сейчас | — |
| Связь (Tie) | не трансформируется: её концы — скважины | — |
| Заблокированные скважины и объекты заблокированных слоев | пропускаются, как в `RotateSelection`. В строке состояния — сколько пропущено | — |

**Проверки перед «Применить».** Масштаб 0 и отрицательный не принимаются: отражение делают кнопки зеркала. Наклон X и Y больше 89° не принимается, наклон Z — любой.

### Зеркало

Две кнопки на числовой панели и в контекстном меню инструмента:

- **«Зеркало по X»** отражает объекты относительно вертикальной плоскости через базовую точку, перпендикулярной оси X: X меняет знак относительно базовой точки.
- **«Зеркало по Y»** делает то же для оси Y.

Оси берутся из выбранной системы: мировые или объекта. Зеркало — часть той же трансформации: в матрице `S` масштаб по оси −1. Значит, оно попадает в предварительный показ и в тот же один шаг отмены. Повторное нажатие снимает отражение.

Что отражение меняет у объектов:

| Объект | Что делается помимо точек |
|---|---|
| Шеврон | левый и правый отрезки меняются местами (`[левый конец, вершина, правый конец]` → наоборот), вместе с их замедлениями: левая сторона остаётся левой |
| Поверхность | у каждого треугольника меняется порядок вершин, чтобы нормали смотрели вверх, как раньше |
| Размер | `Offset` меняет знак, чтобы размерная линия осталась по отражённую сторону |
| Блок | азимут отражается, размеры те же |
| Текст | позиция и угол отражаются, буквы не зеркалятся: текст остаётся читаемым |
| Точка открытия ЭСИ | направление на ряд отражается |
| Скважины, узоры | не отражаются (см. выше) |

## 4. Интерфейс

### Где кнопка

- «Трансформация» — **самостоятельная кнопка панели инструментов** (вертикальная панель слева, `BuildRail`). Она стоит после «Повернуть план» и перед «Измерить», в той же группе, что инструменты положения и вида. Подсвечивается, пока инструмент активен.
- Горячая клавиша: T занята связями, свободны одиночные A, B, C, J. Предлагается **⇧T**; перед внедрением проверить, что сочетание свободно.
- Кнопка «Трансформация» в группе «Линии и полигоны» ленты по-прежнему открывает окно «Преобразование координат»: сдвиг, поворот, общий масштаб. Её подпись меняется на «Преобразование координат», чтобы не путать с новым инструментом. На этапе 5 окно вливается в числовую панель.
- В контекстное меню выделения добавляется пункт «Трансформация».

### Рамка на плане (вид сверху)

Вокруг выделения рисуется рамка в осях, выбранных в панели, с ручками:

| Ручка | Действие | С клавишей |
|---|---|---|
| Угол | масштаб X и Y **пропорционально** | Shift — X и Y по отдельности; Alt — от центра, а не от противоположного угла |
| Середина стороны | масштаб по **одной оси** | Shift — пропорционально по всем осям; Alt — от центра |
| Кружок над рамкой | наклон Z (поворот в плане) | Shift — шаг 15°, Ctrl — шаг 1° |
| Перекрестье в базовой точке | перетащить базовую точку | привязки к вершинам и скважинам |

Во время перетаскивания у курсора видна подсказка: «X 1,25 × Y 1,25» или «Наклон Z 12,5°». Если ввести число и нажать Enter, оно задаёт значение точно, как в инструменте поворота узора.

### В 3D-виде

Над базовой точкой рисуются три оси: X красная, Y зелёная, Z синяя.

- **Кубик на конце оси** — масштаб по этой оси.
- **Дуга вокруг оси** — наклон: дуга вокруг X даёт наклон X, вокруг Y — наклон Y, вокруг Z — наклон Z.
- **Кубик в центре** — масштаб пропорционально.

Это этап 4: наклон удобнее задавать числами, а рамка на плане закрывает масштаб и наклон Z.

### Числовая панель

Открывается на вкладке «Свойства», пока инструмент активен:

| Поле | Значение по умолчанию |
|---|---|
| Масштаб X, Y, Z | 1 |
| Замок «Пропорционально» | включён: одно поле «Масштаб» вместо трёх |
| Наклон X, Наклон Y, Наклон Z, ° | 0 |
| Зеркало по X, Зеркало по Y | кнопки-переключатели |
| Оси | мировые / объекта |
| Базовая точка | центр рамки |
| Кнопки | «Применить» (Enter), «Сбросить», «Отмена» (Esc) |

Рамка и поля связаны в обе стороны: ручка меняет числа, числа перестраивают рамку и предпросмотр.

### Предварительный показ

Объекты рисуются на месте будущего результата, исходные — бледно. В `SceneOptions` поле `MoveOffset` обобщается до `Affine3 MoveTransform` (сдвиг — частный случай). Рендерер уже рисует перемещаемые объекты отдельно (`BeginMove`), там будет `canvas.SetMatrix` для плана. Для 3D-вида и объектов, которые трансформируются по своим правилам, используются временные копии: `Clone` плюс `Transform`. Пересчёт идёт по таймеру отрисовки, не на каждое движение мыши.

**Применение:** одно `Change("Transform", …)` → один шаг отмены. Выделение сохраняется, рамка обнуляется: масштаб снова 1, углы 0.

## 5. Этапы

1. **Ядро.**
   - `Affine3`, `TransformRules`, правила всех типов из раздела 3;
   - скважины и узоры не трансформируются; окружность только равномерно; блок без наклона X и Y; зеркало (шеврон, поверхность, размер);
   - unit-тесты: каждый тип, порядок действий, совпадение со старым окном, обратимость (t, затем t⁻¹ возвращает исходное), пропуск скважин, узоров и заблокированных.
2. **Числовая панель и предварительный показ.**
   - кнопка в панели инструментов, инструмент `TransformTool` с панелью, предпросмотр через `MoveTransform`, «Применить», «Отмена»; замок «Пропорционально», когда в выделении окружность;
   - смоук: открыть, ввести масштаб 2 по X, применить, проверить точки и один шаг отмены; отмена Esc ничего не меняет.
3. **Рамка на плане.**
   - ручки масштаба и наклона Z, кнопки зеркала, Shift, Alt и Ctrl, ввод числа во время перетаскивания, перенос базовой точки;
   - смоук: протяжка угловой и боковой ручки, снимок с рамкой.
4. **Ручки в 3D-виде:** оси, кубики, дуги наклона.
5. **Уборка.**
   - сдвиг X, Y, Z добавляется в числовую панель, старое окно сводится к ней;
   - справка, журнал изменений, ru.tsv.

Каждый этап — записи в CHANGELOG.md и CHANGELOG.en.md и переводы в ru.tsv для всех новых подписей.

## 6. Решения

Решено (2026-11-15):

- **Наклон по осям** — поворот вокруг X, Y и Z. Поля «Наклон X/Y/Z»; отдельного «Поворота» нет.
- **Скважины** не трансформируются: ни масштаб, ни наклон (в том числе вокруг Z), ни зеркало. У них свой инструмент — сетка — и свойства одиночной скважины.
- **Узор** трансформацией не меняется.
- **Окружность** масштабируется только равномерно: когда меняется одна ось, остальные пересчитываются автоматически.
- **Зеркало** нужно, отдельными кнопками «Зеркало по X» и «Зеркало по Y».
- **Блок при наклоне X и Y** пропускается без сообщения.
- **Кнопка** — самостоятельная, в панели инструментов, а не в группе ленты.

## 7. Как сделано (2026-11-15)

- **Ядро:** `Affine3` и `SpatialTransform` в `Domain/Geometry/SpatialTransform.cs`; правила типов — `Entity.Takes(t)` и `Entity.Transform(SpatialTransform)` с переопределениями у текста, окружности, размера, поверхности, линии времени, блока; применение — `Engine/SpatialTransforms.cs`. `GeneralOps.MakeTransform` строится через ту же матрицу.
- **Сетка скважин не трогается совсем:** скважины, связи и полигоны-контуры узоров (`HolePattern.OutlineEntityId`) пропускаются; оси объекта по азимуту узора не делаются.
- **Панель:** поля стоят в плавающей панели инструмента (`ToolPanel`), как у остальных инструментов, а не на вкладке «Свойства». Кнопки — общие «Готово» (Enter) и «Отмена» (Esc).
- **Предпросмотр:** `SceneOptions.Replaced` — рендерер рисует копии объектов на их месте, исходные показаны тонкими серыми линиями; работает и в 3D-виде.
- **Рамка:** угол и сторона переносят базовую точку в противоположный угол или сторону (с Alt — в центр), сдвиг при этом компенсируется, так что результат не прыгает. При наклоне X/Y ручки плана считают масштаб без него.
- **Горячая клавиша:** Ctrl+T (по просьбе); таблица скважин перенесена на Ctrl+Shift+T.
- **Старое окно** «Преобразование координат» сведено к инструменту: пункт меню и кнопка ленты открывают его; класс `TransformParameters` удалён.
