# Окно предпросмотра: проверка печати на macOS и Linux

Печать на Windows проверена через «Microsoft Print to PDF». Код для macOS и Linux только собран: на машине разработки этих систем нет, поэтому его нужно проверить на виртуальных машинах.

## Что подготовить
- Собрать программу под нужную систему: `.\build\build-trial.ps1 -Rid linux-x64` или `osx-arm64`.
- Открыть любой проект со скважинами, нажать Ctrl+P.
- В окне предпросмотра нажать «Печать…».

## macOS
Код: `MacPrinting` в [Printing.cs](../src/BlastDesigner.App/Services/Printing.cs). Использует панель печати через PDFKit и AppKit.

| Проверка | Ожидается |
|---|---|
| Нажать «Печать…» | Открывается системная панель печати с предпросмотром всех страниц |
| Нажать PDF ▸ Сохранить как PDF | Файл совпадает с окном предпросмотра, текст выделяется |
| Отменить панель | Окно предпросмотра остаётся открытым, ошибок нет |
| Альбомная ориентация | Лист не обрезан, поворот правильный |

Если панель не открывается или программа падает, причина почти наверняка в вызовах Objective-C: нужны журнал программы и системный отчёт о сбое.

## Linux
Код: `LinuxPrinting` в том же файле. Использует XDG Portal `org.freedesktop.portal.Print`.

| Проверка | Ожидается |
|---|---|
| GNOME: нажать «Печать…» | Открывается диалог печати рабочего стола |
| KDE: нажать «Печать…» | То же, диалог в стиле KDE |
| Отменить диалог | Ничего не печатается, ошибок нет |
| Печать в файл PDF | Файл совпадает с окном предпросмотра |
| Среда без портала, с CUPS | Отчёт уходит на принтер по умолчанию, программа сообщает об этом |
| Среда без портала и без CUPS | PDF открывается во внешней программе |

Проверить наличие портала: `busctl --user list | grep portal`. Для печати нужен пакет `xdg-desktop-portal` и его реализация для рабочего стола, например `xdg-desktop-portal-gtk` или `-kde`.

## Что прислать при ошибке
Файл журнала из папки настроек (`Logs`), систему и рабочий стол, шаг таблицы, на котором произошла ошибка.
