# Экспорт Davey Tronic (.BPD)

Пункт «Экспорт ▸ Файл Davey Tronic (.BPD)...» (`MainViewModel.ExportBpd`). Окно — `Views/BpdExportWindow.cs`, файл —
`IO/DaveyTronic.cs` (`Build`, `Write`). Пишется `PU_AUTO_BLASTPLAN.BPD`: ASCII, CRLF, контрольная сумма CRC-16/X-25 по
элементу `DATA`.

## Окно, сверху вниз

**Заголовок файла (HEADER)**

| Поле | По умолчанию | Правило |
|---|---|---|
| Полное имя (FULL_NAME) | сохранённое в проекте, иначе номер взрыва, без него — название (`DaveyTronic.DefaultFullName`) | до 30 знаков, в файл как есть |
| Отображаемое имя (DISPLAYED_NAME) | сохранённое в проекте, иначе первые 8 знаков полного имени заглавными; пока его не правили, следует за полным | до 8 знаков; в файле дополняется «_» до 8 (`PadDisplayed`); рядом — как его покажет пульт |
| Дата и время (DATE · TIME) | момент открытия окна, кнопка «Сейчас» | `YYYY/MM/DD` и `HH24:MI:SS`, подсказки под полями |
| Источник (SOURCE_FILE) | «Blast Designer 0.3.x» | печатные латинские знаки, до 32 |
| Зона UTM линий | система координат площадки | номер 1–60, полушарие N / S; только для этого файла: площадка не меняется, в проекте не запоминается |

Имена — по правилу `DaveyTronic.ToFileName`, прямо при вводе и вставке:
- латинские буквы и цифры остаются;
- кириллица — латиницей по ГОСТ 7.79-2000 (система Б, без диакритики), но Ц → Ts; Ё → Yo, Ж → Zh, Х → Kh, Ч → Ch,
  Ш → Sh, Щ → Shch, Ы → Y, Э → E, Ю → Yu, Я → Ya, Й → Y; Ь и Ъ убираются; регистр сохраняется;
- любой другой знак — «_», подряд идущие «_» сжимаются в один; «_» в начале и в конце остаются;
- предел длины — после замены (Щ — четыре знака).
«Карьер Север, блок 12» → «Karer_Sever_blok_12».

После записи файла имена сохраняются в проекте (`BlastProject.BpdExport`, шаг отмены «Имена экспорта BPD»); при «Отмене»
не меняются. Дата, время, источник и зона не хранятся.

**Порядок детонаторов в скважине:** «Верхний / Нижний» — какой детонатор скважины LEVEL 1. Замедления всегда в мс.

**Линии (PATH):** строка на цепочку связей ЭСИ (изделие связи — электронный детонатор, `DaveyTronic.IsElectronicTie`),
по литерам маршрутных номеров (`DaveyTronic.Lines`). Колонки: литера, PU Serial Number, цепочка, скважины, детонаторов
(сколько электронных детонаторов линия даст в файл), знак «больше 800 связей». Стрелка раскрывает рамку линии
(DETZONE): рисунок рамки со скважинами и четыре угла E/N в метрах UTM; считается, не правится. Детонаторы и рамка — из
`DaveyTronic.Preview`, то есть тем же построением, что и файл.

**Итоги:** линий (PATH_QUANTITY) и детонаторов (TOTAL_DETS_QUANTITY), как в файле.

Ошибки (пустое имя, дата или время не по маске, зона вне 1–60, номер пульта не целое число) видны сразу; «Записать
файл…» с ними не закрывает окно. `DaveyTronic.Build` проверяет заголовок ещё раз и с ошибкой файл не строит.

## Файл

- `HEADER`: дата, время, имена, источник — из окна; количества считаются.
- `DETZONE` каждой линии: `UTM_ZONE_LETTER` — полушарие (N/S), `UTM_ZONE_NUMBER` — номер зоны из окна; углы — рамка
  скважин линии (смещение площадки прибавлено, запад/юг вниз, восток/север вверх до метра).
- Без заголовка (`header: null`, тесты и старые вызовы) — имя взрыва, текущий момент и зона площадки, как раньше.
