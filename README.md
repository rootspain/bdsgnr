# Blast Designer

Кроссплатформенная (Windows / Linux / macOS) программа проектирования взрывов на карьерах на C# и Avalonia 11.
Вторая версия Blast Designer: к возможностям первой версии добавлены новые функции проектирования, анализа и обмена данными.
Файлы `.bdp` совместимы с первой версией Blast Designer.

## Структура

| Проект | Назначение |
|---|---|
| `src/BlastDesigner.Domain` | Модель: взрыв, слои, скважины, колонки заряда, продукты, связи, поверхности; правила инициирования, допуски, MWD, система координат |
| `src/BlastDesigner.Engine` | Сетки и ряды, заряжание (с альтернативами), инициирование, времена, поверхности, ведомости, сейсмика, прогноз разлёта и фрагментации, закон затухания, анализ ЛНС, CAD-операции |
| `src/BlastDesigner.IO` | `.bdp` (ZIP + JSON), шаблоны, CSV, DXF/DWG, STR, OBJ, XML буровой карты, KML/KMZ, LAS, IREDES, MWD, отчёты CSV |
| `src/BlastDesigner.Rendering` | Отрисовка плана/3D на SkiaSharp, PDF-отчёты и печать плана |
| `src/BlastDesigner.App` | Интерфейс Avalonia: меню, панели, инструменты, диалоги, окна анализа; перевод в `Services/ru.tsv` |
| `tests/BlastDesigner.Tests` | Модульные тесты (xUnit), в том числе `Version6Tests.cs` |
| `tests/BlastDesigner.UiSmoke` | Автотест реального окна без экрана (Avalonia.Headless) со скриншотами всех новых окон |

## Интерфейс

Тёмный интерфейс по этапам работы:

- **Заголовок:** быстрые кнопки, имя взрыва (свойства, проектные данные, ресурсы), поиск команд и скважин (Ctrl+K), классическое меню целиком (кнопка «Меню»), настройки, справка.
- **Лента по 7 этапам** (Alt+1…7): Файл, Съёмка, Расстановка, Зарядка, Инициирование, Анализ, Выдача — 176 команд; кнопки ленты вызывают те же команды, что и классическое меню. Функции, которых нет в программе (облачные сервисы, оборудование), показаны с замком.
- **Панель видов слева** с клавишами: V выбор, H панорама, Z рамка, Home всё, Shift+Z предыдущий вид, O 3D, N север, M измерить, W рисование, S привязка, G сетка, F7 слои.
- **Над планом:** План / 3D / Разрез, чипы «Время», «Заряд 3D», «Подписи», «Траектории», «Связи», компас направления взрыва.
- **Плавающая панель инструмента:** параметры (ЛНС, шаг, диаметр, угол, схема для сетки), Координаты (Tab), Отмена (Esc), Готово (Enter).
- **Инспектор справа:** Свойства (с кнопками «Похожие», «Такие же», «Инверсия», «Только выбранные»), Слои, Видимость.
- **Контекстное меню по объекту:** скважины, линия, контур, поверхность, точки, пустое место.
- **Снизу:** таблица скважин (Ctrl+T) и быстрые фильтры со счётчиками (пустые, с замером, отказы, без программы ЭСИ).
- **Клавиши этапов:** D скважина, R ряд, P сетка, L зарядить, T связи, E время щелчком, X разрез; Ctrl+E пустые скважины, Ctrl+M отказы, Ctrl+G группа, Ctrl+Shift+V/Q/L/S/X/D — изолинии, ведомость, заряд в 3D, разрез, IREDES, сводка.

## Что добавлено по сравнению с первой версией Blast Designer

**Проектирование**
- Правила инициирования (Правка ▸ Правила инициирования; Инструменты ▸ Скважины ▸ Применить только правила инициирования): детонатор, боевик, число боевиков и замедление по типу скважины, ряду, горизонту и длине.
- Альтернативы в правилах заряжания: другое ВВ для обводнённой части, для крепких и слабых интервалов по данным MWD, дополнительная забойка при слабом устье.
- Проектные допуски и проверка «проект/факт»: устье, глубина, забой, угол, азимут, признак перебуривания.
- Пласты: пересечения скважин с поверхностями типа «Пласт», тип породы по пластам, экспорт пересечений.
- Криволинейная раскладка, смещение полилинии, продление линии до пересечения, середины отрезков, скважины из полилиний, удаление скважин вне полигона.
- Минимальная и максимальная поверхность, пересечения нескольких поверхностей, расширение поверхности до полигона.

**Анализ и прогноз**
- Сводная панель (показатели проекта, заряжания, времени, воздействия, фрагментации и качества).
- Проверка ЛНС, профиль ЛНС первого ряда по бровке и подошве, совпадение времён соседних скважин, обзор объёмов по рядам и типам, заряд по времени.
- Прогноз разлёта (выброс с откоса, кратер, вылет забойки по Richards & Moore) и зона безопасности.
- Прогноз фрагментации: Кузнецов-Рам и Swebrec, X20/X50/X80, негабарит и мелочь.
- Калькулятор закона затухания: регрессия по событиям, доверительный уровень по Стьюденту, допустимый заряд и расстояние.
- Расчёт опасной зоны: максимум из сейсмики, воздушной волны и разлёта.

**Обмен данными**
- KML/KMZ (импорт и экспорт, пересчёт UTM ↔ WGS84), облака точек LAS 1.0–1.4, план и файл качества IREDES, данные MWD, расширенные данные взрывания, профили скважин.

**Исправлено**
- Объём и удельный расход для выбранной части скважин считались по ячейкам, растянутым на весь контур взрыва (объём завышался примерно в 10 раз). Теперь ячейки строятся по всем скважинам.

## Что ещё не реализовано

- Единицы измерения (имперские), языки кроме русского и английского.
- Форматы E57, POD, GeoTIFF, Surpac DTM, Carlson, RHINO, DeviGyro/DeviShot, cBlast, Leica, Excel-ведомости.
- Электронное взрывание: контурное время, последовательность кодирования, отчёты EBS.
- Модель MSW, калькулятор зоны слияния, оценка съёмки, вид ряда, менеджер пород и менеджер поверхностей, ленточный интерфейс.
- Намеренно не делается: облачные сервисы, работа с оборудованием электронного взрывания, обновления, активация и лицензирование.

Формат IREDES написан по публичному описанию стандарта и не проверялся на схеме конкретного производителя станков.

## Сборка и запуск

```bash
dotnet run --project src/BlastDesigner.App
dotnet test tests/BlastDesigner.Tests
dotnet run --project tests/BlastDesigner.UiSmoke -- ./smoke-out
```

Публикация (самодостаточная):

```bash
dotnet publish src/BlastDesigner.App -c Release -r win-x64 --self-contained true -o out/win-x64
dotnet publish src/BlastDesigner.App -c Release -r linux-x64 --self-contained true -o out/linux-x64
dotnet publish src/BlastDesigner.App -c Release -r osx-arm64 --self-contained true -o out/osx-arm64
```

Пробная версия (без лицензии и интернета):

```bash
dotnet publish src/BlastDesigner.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:Trial=true -p:TrialDays=30 -o out/win-x64-trial
```

- `TrialDays` (по умолчанию 30) отсчитываются от первого запуска этой версии программы; у следующей версии свой пробный период.
- Каждый запуск записывается (время UTC, журнал последних 20 запусков) в реестр `HKCU\Software\BlastDesigner\Trial`,
  в `trial.dat` в папке настроек и в `%LocalAppData%\.bdcache\state.bin`. Записи подписаны ключом, привязанным к компьютеру:
  изменённая или перенесённая запись завершает пробный период; удалённая копия восстанавливается из остальных.
- Самое позднее время запуска только растёт (во время работы — и по внутреннему таймеру, независимо от часов), дни считаются от него,
  поэтому перевод часов назад ничего не даёт. Если часы отстают от него больше чем на 2 часа, программа просит установить правильное время.
- `-p:TrialValidDays=N` (по умолчанию выключено) — сборка перестаёт запускаться через N дней после даты сборки, даже если все записи удалены.
- Пока срок идёт, в заголовке окна показано «Триал (N)» — сколько дней осталось. Обычная сборка без `-p:Trial=true` — полная версия.

Сборка с обфускацией (прячет секрет проверки триала, путь в реестр и приватные члены в `BlastDesigner.dll`):

```powershell
pwsh build/build-trial.ps1                     # папка out/win-x64-trial
pwsh build/build-trial.ps1 -SingleFile         # один exe без dll: out/win-x64-trial-exe/BlastDesigner.exe
pwsh build/build-trial.ps1 -Days 14 -ValidDays 45 -SingleFile
```

Скрипт сначала собирает и обфусцирует `BlastDesigner.dll` (Obfuscar, настройки в `build/obfuscar.xml`), и только потом
упаковывает — поэтому обфусцированный код попадает и в единый exe (`-SingleFile`: нативные библиотеки вшиты внутрь, сжатие
включено). Готовую сборку проверяет через `--selftest`. Публичный API, свойства модели и ресурс `ru.tsv` не трогаются,
иначе сломались бы формат `.bdp`, привязки таблиц и сетка свойств.

Настройки хранятся в папке пользователя `BlastDesigner` (AppData на Windows, `~/.config` на Linux,
`~/Library/Application Support` на macOS).
